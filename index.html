Atlas Parallax Studio

A local Pyto-powered, depth-map stereogram maker. The HTML controls run in Safari; Python generates the actual pixels on your device.

1 · Upload your image

Choose a JPG/PNG/WEBP image. For genuine shape-based 3D, upload a grayscale depth map (white = closer, black = farther). A normal photo has no depth information; the "photo approximation" mode estimates depth from brightness and will not recover actual object geometry.

4 · How to view

Look through the image with relaxed, parallel eyes until repeated tiles fuse. For a large wall print, try 7–10 feet. Begin with the cube test. Small-screen previews are for testing the encoding, not calibrating the final wall viewing distance. If the depth looks inverted, change the shift sign in the Python code (see README).

The app writes files to Pyto's Documents/AtlasParallaxOutputs folder. Very large renders may exhaust iPhone memory; try preview or 75 DPI first. The stereogram is depth-dependent horizontal pattern displacement; this version does not implement complete hidden-surface occlusion correction.
