Atlas Parallax Upload Studio for Pyto

1. Install Pillow and NumPy in Pyto.
2. Run atlas_parallax_upload_pyto.py.
3. Open http://127.0.0.1:8778 in Safari.
4. Choose image > Upload image > Generate selected image.
5. Files are saved under Documents/AtlasParallaxOutputs.

Depth map uploads: white means near, black means far. Normal photos have no true depth information; brightness approximation is not real depth estimation.

Start with portrait preview. Full-size outputs use substantial memory.

No Image.Resampling API is used.
